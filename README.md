# CS2 / KHL / Football Analytics Bot

Telegram-бот для спортивной аналитики по CS2, КХЛ и футболу.

## Текущий режим КХЛ

КХЛ работает в режиме **real browser web research**:

- расписание матчей собирается через Chromium;
- поиск выполняется через публичные поисковые страницы (Yandex → Bing → Google);
- найденные страницы открываются самим Chromium и читаются как веб-доказательства;
- собираются составы, травмы, дисквалификации, вратари, форма, H2H, таблица и новости;
- коэффициенты ищутся только для Winline, Фонбет, BetBoom и Parimatch;
- API-Sport, KHL Mobile API, SofaScore и другие спортивные API в рабочем контуре КХЛ не используются;
- если подтверждённого коэффициента нет, бот не придумывает линию и не выдаёт ставку.

## Что уже есть

- Telegram-меню с разделами CS2 / КХЛ / футбол;
- SQLite-хранилище истории прогнозов;
- расчёт fair odds и Value;
- рейтинг сигналов по вероятности и Value;
- автоматическая статистика проходимости сохранённых прогнозов;
- browser-only слой для КХЛ;
- фильтр ИИ: не обязательно выдавать прогноз на каждый матч, только сильные кандидаты.

## Запуск на Windows

```bat
python -m venv .venv
.venv\\Scripts\\activate
python -m pip install -r requirements.txt
python -m playwright install chromium
copy .env.example .env
notepad .env
python -m app.main
```

В `.env` необходимо заполнить:

```text
BOT_TOKEN=токен_telegram_бота
OPENAI_API_KEY=ключ_ИИ
OPENAI_BASE_URL=если_используется_совместимый_API
OPENAI_MODEL=модель
```

После установки Playwright бот сам запускает Chromium в headless-режиме. Отдельно открывать Chrome не требуется.

## Архитектура КХЛ

```text
Telegram
   ↓
KHL calendar
   ↓
Chromium browser
   ├─ Yandex
   ├─ Bing / Google fallback
   ├─ KHL / клубы
   ├─ Sports.ru / Championat / СМИ
   └─ Winline / Fonbet / BetBoom / Parimatch
   ↓
Web evidence dossier
   ↓
AI analyst
   ↓
quality + value filter
   ↓
только сильные прогнозы
   ↓
Telegram
```

## Правила достоверности

- Отсутствие игрока в найденном составе само по себе не означает травму.
- Кадровая информация должна иметь подтверждение публичного источника.
- Для свежих новостей приоритет имеют официальные источники КХЛ/клубов, затем крупные спортивные СМИ.
- Коэффициент принимается только при явной привязке к матчу и одному из разрешённых букмекеров.
- Неидентифицированная линия и предположительный коэффициент отбрасываются.
- ИИ получает веб-доказательства и не должен дополнять отсутствующие факты памятью модели.

## Принцип модели

`Value = probability × odds - 1`.

Бот является аналитическим инструментом и не размещает ставки автоматически.
