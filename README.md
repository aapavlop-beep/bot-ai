# CS2 / KHL / Football Analytics Bot

Telegram-бот для спортивной аналитики по CS2, КХЛ и футболу.

## Что уже есть

- Telegram-меню с разделами CS2 / КХЛ / футбол;
- SQLite-хранилище истории прогнозов;
- расчёт fair odds и Value;
- рейтинг сигналов по вероятности и Value;
- абстракция источников данных;
- адаптер The Odds API для линий, где нужная лига и рынки доступны;
- конфигурация секретов через `.env`;
- автоматическая статистика проходимости сохранённых прогнозов.

## Архитектура

```text
Data providers
      ↓
Normalizer
      ↓
Features / team form / rosters / maps / xG / H2H
      ↓
Sport-specific probability models
      ↓
Calibration
      ↓
Market + Value engine
      ↓
Telegram Bot / Mini App
      ↓
Prediction history → Backtesting → Model improvement
```

## Источники данных

Источник выбирается отдельно для каждого спорта. Это важно: один API не обязан качественно покрывать CS2, КХЛ и футбол одновременно.

Для футбола можно использовать специализированные football APIs со статистикой и xG. Для КХЛ нужны источники с российской лигой и историей; коммерческие feed-провайдеры предлагают KHL, составы, статистику, H2H и prematch/in-play odds. Для CS2 нужен отдельный esports provider.

## Запуск

```bash
python -m venv .venv
# Windows
.venv\\Scripts\\activate
pip install -r requirements.txt
copy .env.example .env
python -m app.main
```

В `.env` необходимо заполнить `BOT_TOKEN`. `ODDS_API_KEY` пока необязателен и используется только для включения соответствующего адаптера.

## Принцип модели

Бот не должен выдавать придуманные проценты. Вероятность должна поступать из аналитической модели, построенной на фактических данных и затем проверенной backtesting'ом.

`Value = probability × odds - 1`.

Например, если модель оценивает событие в 62%, а коэффициент равен 1.80, ожидаемое преимущество составляет 11.6% до учёта ошибок модели и комиссий.
