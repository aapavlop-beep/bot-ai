# CS2 / KHL / Football Analytics Bot

Telegram-бот для спортивной аналитики по CS2, КХЛ и футболу.

## Цели

- собирать данные о матчах и линиях;
- рассчитывать вероятности событий аналитической моделью;
- сравнивать модельную вероятность с коэффициентом и считать Value;
- ранжировать большое количество рынков;
- показывать причины сигнала и уровень уверенности;
- сохранять результаты прогнозов для последующей проверки точности модели.

Бот является аналитическим инструментом и не размещает ставки автоматически.

## Архитектура

```text
Data providers -> Normalizer -> Feature engine -> Prediction models
                                               -> Market/value engine
                                               -> Telegram Bot / Mini App
                                               -> Prediction history
```

## Структура

- `app/models.py` — доменные модели спорта, матча и рынка.
- `app/engine.py` — расчёт fair odds и Value и ранжирование рынков.
- `app/bot.py` — Telegram-интерфейс.
- `app/config.py` — конфигурация через переменные окружения.

## Запуск

```bash
python -m venv .venv
# Windows: .venv\\Scripts\\activate
pip install -r requirements.txt
copy .env.example .env
python -m app.main
```

Заполни `BOT_TOKEN` в `.env`.
